# Job Search Strategy

The automation is most effective when aimed at high-value, low-competition
postings. This page captures the search strategy used with the tool.

## Tiered search list (in priority order)

1. **AI Agent Developer / LangChain** — strongest differentiators, premium rates.
2. **React Python AWS** — enterprise stack, matches enterprise experience.
3. **Next.js FastAPI** — modern full-stack, growing demand.
4. **VR/Unity developer** — unique skillset, very little competition.
5. **Full stack React Python** — broad, but good with filters.
6. **React TypeScript / Python Django** — selective, solid matches.

## Filter settings

- Hourly rate **$50+** (matches a high-end profile rate).
- Fixed-price projects **$1K+**.
- Experience level: **Intermediate / Expert only**.
- Proposals: **less than 5** (higher chance of being read; first-5 applicants
  convert at a much higher rate).
- Apply to jobs posted in the **last 24 hours** when possible.

You can pre-filter in the browser with URLs like:

```
https://www.upwork.com/nx/search/jobs/?amount=1000-4999,5000-&contractor_tier=2,3&hourly_rate=50-&nbs=1&proposals=0-4&q=<query>
```

## Principles

- **Quality over quantity** — a handful of strategic applications beats scores
  of random ones.
- **First-line hook** — the generated letters open by referencing the client's
  actual requirements.
- **Customise** — always tweak the first/last paragraphs and adjust the bid rate
  to match the posted budget before submitting.
